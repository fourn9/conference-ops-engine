# Event workspace

Read `AGENTS.md`, `conference/event.md`, and `docs/configuration.md`. Reusable instructions live in `.claude/skills`, `.claude/commands`, and `methodology/` after sync. Workflows contain their own agent prompts and schemas; use the Node runner if the host has no Workflow tool.

At session start, read existing `conference/Memory.md`, `local/vault/Memory.md`, and recent decisions when relevant. At the end, record decisions and next actions locally. Journal summarization is disabled until `local/journal-enabled` exists or `CONFERENCE_JOURNAL_ENABLED=1` is set. Before enabling, read `journal/README.md`.
