# Daily Brief（今日のタスク整理）

## 使用タイミング

朝の業務開始時、または1日の途中で「今やるべきこと」を整理したい時。
明示的に `/daily-brief` で呼び出すことが多い。

## 実行手順

以下を順番に実行：

### 1. Gmail の確認
- 直近24時間の未読メール
- 要対応のものを抽出（外部スポンサー・登壇者からの返信、社外からの新規問い合わせ）
- 件名・差出人・要点・期限の有無を整理

### 2. Slack の確認
- DM・メンション（自分宛）の未読
- 要返信のものを抽出
- 緊急度の高いものを優先

### 3. Google Calendar の確認
- 今日の予定
- 各予定について：
  - 準備が必要か
  - 資料・議題の用意があるか
  - 移動を伴うか

### 4. 統合してアウトプット

以下のフォーマットで出力：

```markdown
# Daily Brief - [日付]

## 🔥 今すぐ対応
[緊急かつ期限が今日中のもの]

## 📅 今日中に
[今日対応が望ましいもの]

## 💭 今週中に
[期限はあるが急ぎではないもの]

## 📆 今日の予定
[カレンダーの予定 + 準備が必要なもの]

## 💡 補足
[気になる傾向、まとめての対応提案など]
```

## 出力時の注意

- 個人情報（顧客の電話番号など）は要約で出力、生データは含めない
- 機密性の高いやり取り（金額交渉中など）は「[件名のみ：社内秘]」とする
- リンクは Notion・Slack 内のものは生 URL、メールは件名のみ
- 推測で「重要」とラベル付けしない。事実ベースで

## 安全装置

- このスキルは**読み取りのみ**。返信・送信は行わない
- 「自動的に返信する」「カレンダーに予定を追加する」などの提案は
  ユーザーから明示的な指示があるまで行わない

## 関連

- 個別の返信が必要になったら `japanese-business-email` スキルを使う
- 登壇者対応が必要なら `speaker-outreach` スキルを参照

接続先・保存先の共通設定は `docs/configuration.md` を参照。既にユーザーが明示した条件は再確認せず、その範囲で進める。
