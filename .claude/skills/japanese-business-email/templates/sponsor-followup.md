# スポンサーフォローアップ テンプレート

## 用途
スポンサー企業へのフォローアップ。
イベント終了後、提案後、契約検討中などのフェーズで使用。

## イベント終了後（例）

```
件名：[イベント名] のご協賛、誠にありがとうございました

[企業名] [担当者名]様

[主催組織]の[自分の名前]です。

先日は [イベント名] へのご協賛、誠にありがとうございました。
おかげさまで、[具体的な成果：参加者数・反響など]という結果となりました。

ブースでは [具体的な来場者の様子・印象的なエピソード] が見られ、
[企業名]様の認知向上に貢献できていれば嬉しく思います。

イベント全体の参加者アンケート結果を簡単にまとめましたので、
別添にてお送りします。次回開催に向けたご相談も含めて、
お打ち合わせの機会をいただけますと幸いです。

[次回イベント名] のご案内も近日中にお送りいたします。

──────
[署名]
```

## 提案後フォローアップ（例）

```
件名：[イベント名] ご協賛のご検討状況について

[企業名] [担当者名]様

お世話になっております。[主催組織]の[自分の名前]です。

先日お送りした [イベント名] のスポンサープランについて、
ご検討状況はいかがでしょうか。

不明点や、プラン内容のカスタマイズのご希望などございましたら、
お気軽にお声がけください。

[締切がある場合：締切日を明記]

──────
[署名]
```

## 契約フェーズでの確認（例）

```
件名：[イベント名] スポンサー契約書の送付

[企業名] [担当者名]様

[主催組織]の[自分の名前]です。

[イベント名] のスポンサー契約書を別添にてお送りします。

ご確認いただき、修正点等ございましたらお知らせください。
内容にご同意いただけましたら、ご返送をお願いいたします。

支払い条件：[条件]
スポンサー特典：[要点]

──────
[署名]
```

## 注意事項

- 金額や契約条件の数字は必ず人間が確認する
- 過去のスポンサーは温度感が違うので、関係性に応じて文面を調整
- 添付資料の有無は最後に必ずチェック
