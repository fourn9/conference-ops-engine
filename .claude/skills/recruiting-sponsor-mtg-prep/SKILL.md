# 採用企業スポンサーの登壇すり合わせMTG準備

## 原則

1. **与件の正は商談の一次情報。** 文字起こし全文、会議サマリ、社内商談記録の順で確認し、固有名詞と数字を裏取りする。
2. **参考記事は本文まで読む。** 一覧や要約だけで企画の根拠にしない。
3. **ターゲットは先方の採用ターゲットを写さない。** イベント来場者の構成と交差させて設計する。
4. **企画案は2〜3本出す。** 先方の方向を磨く案と、視野を広げる案を用意する。
5. **採用目的では会社紹介を主役にしない。** 具体的な制約、設計判断、変遷、失敗から実践知を示す。

## 手順

1. 商談記録、既存企画書、契約条件を読み、登壇者・採用課題・協賛目的・期限を整理する。
2. テックブログ、求人、登壇者の発信を調べ、本文確認済みの根拠を記録する。
3. イベントのテーマ・想定来場者と採用ターゲットを突き合わせる。
4. 基調講演、他スポンサー、同社の過去登壇との重複を確認する。
5. 各案を「具体的な導入状況 → 設計判断 → 変遷や失敗 → 持ち帰り」で組み立てる。
6. 企画書には参加者向けの内容だけを記載し、根拠・未確認事項・重複確認は運営用の控えに分ける。

## チェックリスト

- [ ] 商談の一次情報で固有名詞・数字を確認した
- [ ] 参考記事を本文まで読んだ
- [ ] 来場者属性との交点で視聴ターゲットを設定した
- [ ] 各案に固有の制約または実例がある
- [ ] 他セッションと切り口が重複しない
- [ ] 先方の既存記載を壊さず、更新後に読み戻した

接続先・保存先の共通設定は `docs/configuration.md` を参照。既にユーザーが明示した条件は再確認せず、その範囲で進める。
