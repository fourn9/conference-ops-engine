# スポンサーMTGフォロー

## 原則

1. **推測で埋めない。** MTGの文字起こしまたは議事録が得られなければ、成果物を作らず停止して報告する。
2. **作成まで。送信しない。** メールは下書きのみとし、送信・企画書への反映・チャット投稿は人が行う。
3. **合意と提案を混ぜない。** 合意済みの内容、未決事項、主催側の次アクションを明確に分ける。

## パラメータ

| パラメータ | 説明 |
|---|---|
| `COMPANY` | スポンサー企業名（必須） |
| `MEETING` | 対象MTGのIDまたは日時（任意） |
| `DOC_URL` | 企画書URL（任意） |

## 手順

1. `MEETING` が未指定なら、企業名と直近1か月を目安に候補を検索し、対象を確認する。
2. 会議サマリ、文字起こし、社内議事録の順に取得する。テキストがなければ停止する。
3. 企画書を読み、既存案とMTGで決まった変更点を照合する。記載例を合意事項として扱わない。
4. 次の構成でローカルサマリを作る：合意した方向性／登壇者／未決事項／先方の宿題／主催側の宿題／企画書へ転記するテーマ案。
5. お礼、合意内容、双方の宿題と次アクションを含むメール下書きを作る。宛先を推測せず、未確定なら確認する。
6. サマリのパスとメール下書きを報告し、未決事項を明示する。

## チェックリスト

- [ ] 根拠にしたMTGテキストをサマリに明記した
- [ ] テキストがない場合は推測生成しなかった
- [ ] 合意事項と未決事項を分離した
- [ ] メールは下書きだけで送信していない
- [ ] 宛先アドレスを推測していない

接続先・保存先の共通設定は `docs/configuration.md` を参照。既にユーザーが明示した条件は再確認せず、その範囲で進める。
