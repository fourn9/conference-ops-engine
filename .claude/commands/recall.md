# /recall <keyword>

セッションジャーナル（`journal/`）を検索し、過去の対話の経緯・決定・棄却理由を引く。
「前に話したあれ」「なぜこの案にしなかったか」を確認するときに使う。

## 動作

1. `bash .claude/scripts/journal-search.sh "<keyword>"` を実行
2. ヒットをセッション別に整理して提示（INDEX 行 → 該当エントリ）
3. 関連が強いエントリはファイルを読み、「決定（確定）」と「未決・棄却」を区別して要約する
4. ジャーナルで足りない場合のみ、生 transcript 検索（search.sh が末尾に表示するコマンド）を
   ユーザーに確認してから実行する（重い・全対話が対象）

## 注意

- journal エントリの「決定（確定）」以外を確定事項として扱わない（README.md の契約）
- ヒットした内容と現在の依頼が食い違うときは、その差分を明示して確認する
