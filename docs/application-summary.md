# Application-ready project description

## Short English version

I built an AI-assisted workflow engine for technical conference operations, covering audience research, speaker discovery, outreach preparation, and sponsor workflows. I separated reusable procedures from event-specific data, added evidence checks to research, and created versioned distribution so individual event workspaces could share improvements. This public case study includes a new offline demo using synthetic data.

Project: https://github.com/fourn9/conference-ops-engine

## 日本語

技術カンファレンスの企画・運営を支援するAIワークフロー基盤を開発しました。対象者調査、登壇候補の発掘、招待文の準備、スポンサー対応などを共通化し、イベント固有データと再利用する手順を分離しました。調査結果の根拠確認と、共通エンジンをバージョン指定で配布する仕組みを実装しています。公開版には設計説明と架空データで動く新規デモを収録しています。

## Combined description for both projects

I built an AI-assisted conference operations system with two layers: a reusable workflow engine and event-specific workspaces. The engine organizes research, evidence checks, and repeatable operational tasks. The workspace organizes execution and decision history, including a session-journal prototype that separates confirmed decisions from unresolved ideas. I developed the system with AI coding assistants. The public repositories explain the architecture and provide newly written synthetic demos; the original operational material remains private.

- https://github.com/fourn9/conference-ops-engine
- https://github.com/fourn9/conference-ops-workspace

These descriptions focus on implementation and design, without quantitative adoption or productivity claims.
